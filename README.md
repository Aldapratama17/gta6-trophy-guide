# Vice City Ledger — GTA VI Trophy Guide & Tracker

An offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI, built for [make.fun's gta6-trophy-guide-01 bounty](https://make.fun/bounty/gta6-trophy-guide-01?utm_source=github&utm_medium=readme&utm_campaign=gta6-trophy-guide-01).

Static files under `app/` (no build step, works with the network off): checklist saved in the browser, export/import, filters, spoiler mode, a roadmap to the platinum, missable flags and a cited guide for every trophy. `main.ts` hands in `app/`, `screenshots/` and `dossier.json`.

Run: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
